경조금 관리 웹앱 - Cafe24 PHP 8.x / MySQL

1. ZIP을 풀어 /www/congrate_app/ 경로에 업로드합니다.
2. config.php의 APP_SETUP_KEY를 반드시 긴 임의의 비밀문자열로 바꾸고 APP_BASE_URL을 실제 주소로 조정합니다.
3. 기존 공통 DB 설정 파일은 /www/private_config/db_common.php에 있어야 합니다. 다른 위치라면 config.php의 require 경로를 변경하세요.
4. https://도메인/congrate_app/setup.php 에서 설치키/관리자 아이디/12자 이상 비밀번호를 입력해 DB 테이블을 생성합니다.
5. 설치 후 setup.php, schema.sql 파일을 서버에서 반드시 삭제하세요. initial_data.csv도 가져오기 완료 후 서버에서 삭제하세요.
6. 로그인 후 CSV 관리에서 initial_data.csv를 업로드합니다. 53건 원본 중 유효행이 등록됩니다.
7. 연락처 메뉴에서 휴대전화번호를 입력하고, 경조사 안내 메뉴에서 명단 및 안내문 CSV를 준비할 수 있습니다.

중요:
- 문자/알림톡 자동발송은 아직 연결되지 않았습니다. 발송 명단 준비 기능만 제공합니다. Ppurio 연동에는 발신번호, 승인 템플릿 및 계정 설정과 별도 발송 코드가 필요합니다.
- 동일 이름은 같은 사람으로 간주하므로 동명이인 데이터는 관리자 확인이 필요합니다.
- 초기 CSV에 휴대전화번호가 없으면 직접 입력해야 합니다.
- 개인정보 보호를 위해 HTTPS와 서버 백업을 사용하고, CSV 다운로드 파일을 안전하게 관리하세요.
- 관리자 접근은 반드시 개인 비밀번호로 통제하고 설치 후 setup.php를 삭제하세요.
