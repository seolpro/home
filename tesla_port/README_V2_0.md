# Tesla Port v2.0 FINAL

## 공개 index.php 개편
- 일반/미확인 선박 공개 노출 제거
- API024에서 Shanghai 출항이 검증된 자동차운반선만 추적 대상으로 표시
- API001에서 TESLA 화물이 확인된 건을 별도 강조
- 추적 중 / Tesla 확인 / 확인 차량 대시보드
- 차량수량, 총중량, 평균중량, 예상모델, 통관상태 표시
- 마지막 자동확인 시각 표시
- 대상이 없을 때 정상적인 빈 상태 화면 제공

## 설치
기존 v1.9.3.4 위에 전체 덮어쓰기 가능합니다.
추가 SQL은 없습니다.

## 알림톡
v1.9.3.4의 기본형 텍스트 알림톡(ALT) 수정 상태를 유지합니다.
