# Tesla Port Monitor v1.5

## 핵심 변경
- 관세청 API001을 cargMtNo뿐 아니라 MBL/HBL(+입항년도)로 조회 가능
- 다건 응답 시 화물관리번호 후보목록 파싱
- TESLA 판정은 선박명이 아닌 공식 품명(prnm)만 사용해 오탐 방지
- 해수부 mrNum(MRN, 11자리)과 관세청 cargMtNo(15~19자리)를 임의 변환하지 않음
- 향후 자동 브리지용 tp_customs_candidates 테이블 추가

## 업그레이드
1. 기존 config.php 보존
2. 파일 덮어쓰기
3. sql/upgrade_v1_5.sql 1회 실행
4. admin/customs_test.php에서 API001 조회 확인

## 중요: 자동 브리지의 다음 단계
관세청 공식 서비스 목록에는 `입항보고내역조회(해상)` 서비스가 별도로 있으며 적하목록관리번호(MRN), 호출번호 등 해상 입항정보를 제공합니다. 현재 승인받은 API001만으로는 선박명/입항일만으로 화물 전체목록을 검색하는 요청 파라미터가 없습니다. 따라서 완전 자동 연결을 위해서는 해당 입항보고내역조회(해상) OpenAPI를 추가 신청하고 그 연계가이드를 확보하는 것이 안전합니다.
