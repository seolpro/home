# Tesla Port v1.9.1

## 핵심 수정
v1.9에서 API024 조회가 12시간 캐시에 막혀 `api024_checked=0`이 될 수 있던 순서 문제를 수정했습니다.

크론 순서는 다음과 같습니다.
1. MOF 현재 조회기간 선박 수집
2. 현재 조회기간 자동차운반선을 API024로 우선 교차검증 (12시간 캐시 우회)
3. API024 실제 전출항지가 Shanghai/CNSHA/CNSHG인 경우만 후보 인정
4. API024 MRN/제출번호 확보
5. MRN + MSN 후보를 API001로 제한 스캔
6. 실제 API001 응답 화물만 저장
7. 품명 TESLA 탐지 및 수량/중량/통관상태 반영

알림톡 설정은 변경하지 않습니다. 기존 설정이 OFF이면 계속 OFF입니다.
DB/SQL 추가 변경은 없습니다. v1.9의 upgrade_v1_9.sql이 이미 실행된 상태면 추가 SQL 실행이 필요 없습니다.
