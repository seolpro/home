# HRM Plus 범용 인사·휴가관리시스템 V2.0

## 설치
1. `config.sample.php`를 `config.php`로 복사하고 빈 DB 접속정보를 입력합니다.
2. `schema.sql`을 직접 실행하지 말고 브라우저에서 `install.php`만 실행합니다.
3. 조직명과 최초 최고관리자 아이디/비밀번호를 자유롭게 입력합니다.
4. 설치 후 `install.php`, `schema.sql` 접근을 차단하거나 삭제합니다.

## V2 핵심 기능
- 휴가유형 자유 설정, 직원/부서/결재선, 순차승인
- 직원 개인 대시보드(`my.php`): 부여·사용·잔여·결재중·의무사용률·최근 신청
- 비즈뿌리오 알림톡: 신청→결재자, 다음 결재자, 최종 승인/반려→신청자
- 직원별 연도별 월 통상임금 이력
- 연차수당 계산: 월 통상임금 ÷ 209 × 8 × 지급대상 미사용일수
- 전체 계산, 제외/조정일수, 확정/해제, 인쇄, CSV

## 주의
비즈뿌리오 계정별 API 규격이 다른 경우 관리자 설정의 토큰 URL/메시지 URL을 계약 규격에 맞게 입력하세요. 템플릿 변수는 등록된 카카오 템플릿과 정확히 일치해야 합니다.


## 공통 비즈뿌리오 알림 모듈
- 관리자 > 설정: 계정, 인증키, Sender Key, 발신번호, 즉시/대기열 발송 설정
- 관리자 > 알림톡: 이벤트별 템플릿 코드·승인 메시지·버튼 JSON 관리
- 업무 코드에서는 `Notification::dispatch($eventCode, $recipientType, $recipientId, $phone, $variables)` 한 줄로 호출
- 대기열 모드에서는 `notification_cron.php?key=설정한키`를 Cafe24 크론 또는 외부 스케줄러에서 호출
- 공식 v3 메시지 구조(`/v3/message`)에 맞춰 최종 메시지 본문을 전송합니다.

## 최종 알림톡/CRON 설정
- 설치 시 `notification_cron_key`가 64자리 난수로 자동 생성됩니다.
- 관리자 > 설정에서 보안키와 실행 URL을 복사하거나 새 키를 생성할 수 있습니다.
- 새 키를 생성하면 기존 CRON URL은 즉시 무효화됩니다.
- `notification_cron.php` 실행 시 마지막 실행시각 및 결과가 설정 화면에 기록됩니다.
- 비즈뿌리오 인증키 입력란은 보안상 기존 값을 다시 표시하지 않으며, 비워 저장하면 기존 키가 유지됩니다.


## V2 통합 조직·결재·권한 기능
- 부서관리 및 상위부서/부서장 지정
- 직원별 결재선 직접 지정
- 결재선 적용 우선순위: 직원 직접 지정 → 소속부서 결재선 → 전체 기본 결재선
- 신청 시 결재선 ID와 단계별 결재자 스냅샷 저장
- 부서관리자/결재권자별 조회 부서 권한
- 관리자 대시보드 통합 검색
- 직원별·일자별 휴가현황 조회
- 기존 설치본은 migrate_v2_department_scope.sql 실행 후 파일 덮어쓰기
