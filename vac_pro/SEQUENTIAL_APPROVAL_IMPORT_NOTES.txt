HRM Plus V2 순차결재·일괄업로드 통합본

1. 순차결재
- 신청 당시 결재선의 1~3단계를 request_approvals에 스냅샷 저장
- 1차 승인 전 2차/3차 처리 불가
- 현재 pending 단계의 실제 결재권자 계정만 승인/반려 가능
- 최고관리자·인사관리자도 단계를 건너뛰어 승인하지 못함
- 반려 시 이후 단계는 skipped로 종료
- 각 단계 승인 후 다음 결재권자에게 알림톡, 최종승인/반려 후 신청자에게 알림톡
- 결재권자 로그인 계정은 권한계정 관리에서 해당 직원과 반드시 연결

2. 일괄업로드
- 관리자 > 일괄업로드 메뉴
- 직원 CSV: 신규등록 및 기존직원 수정(사번 우선, 없으면 성명 기준)
- 부서가 없으면 자동 생성
- 결재선명은 사전에 등록된 명칭과 일치해야 함
- 기승인 휴가 CSV: 승인완료 상태로 등록, 결재이력 생성 안 함
- 승인 사용일수, 잔여연차, 연차수당 계산에 자동 반영
- UTF-8, CP949, EUC-KR CSV 지원
- 샘플 파일은 samples 폴더에 포함

3. 기존 DB 업데이트
- 파일 전체 덮어쓰기 전 DB 백업
- migrate_v2_sequential_import.sql 실행
- 권한계정 관리에서 각 결재권자 계정의 직원 연결 확인

4. 신규 설치
- 빈 DB에서 install.php만 실행(schema.sql 직접 실행 금지)
