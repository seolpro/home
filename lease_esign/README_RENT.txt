월차임 알림톡 업데이트
1. 기존 파일 및 DB 백업. ZIP의 lease_esign 폴더 내용을 기존 동일 경로에 업로드. config.php, lib.php, storage, 기존 계약 테이블은 변경하지 않음.
2. 관리자 로그인 > 월차임 납부 안내 > DB 초기 설치. 신규 4개 테이블만 생성.
3. 기존 문자설정의 뿌리오 계정/인증키 확인. 알림톡 설정에서 승인 템플릿 코드 입력. 발신 프로필은 계정에서 필요한 경우만 입력. 실제 발송은 기본 비활성.
4. 계약 등록 후 월별 리스트에서 관리자 번호로 테스트. 테스트는 실제 알림톡을 보내지만 월별 상태는 변경하지 않음. 승인 변수 순서와 실제 API 응답 확인 후 활성화.
5. GAS 새 프로젝트에 rent_trigger.gs 붙여넣기. 프로젝트 설정 > 스크립트 속성 RENT_API_URL = https://본인도메인/lease_esign/api/rent_alimtalk_gas.php, RENT_API_KEY = 관리자 화면 인증키. 시간대 Asia/Seoul. installRentTrigger 실행 및 권한 승인. 5분 간격 호출, 정확한 분 단위 보장 없음.
6. 기존 SMS API는 활성 등록된 전자계약을 제외하도록 변경됨(알림톡 비활성 상태에서도 제외). 전환 전 테스트 완료 및 활성화 필요. 오프라인 계약은 기존 SMS 대상 아님. 기존 GAS 트리거는 미등록 계약에 SMS가 필요하면 유지.
7. 당월/익월 리스트 생성. 납부일 없는 달 말일 적용. 예정 시간이 지났어도 납부일 이내이면 다음 호출 시 발송. 실패는 수동 재발송, 불명/처리중은 공급자 조회 후 관리자가 확인해야 하며 자동 재시도하지 않음. 접수 완료는 실제 수신 성공과 다름. 기존 SMS 이력은 신규 큐에 이관하지 않으므로 전환 월에 이미 SMS를 보낸 건은 이번 달 제외 처리.
8. API는 기존 소스의 토큰 함수를 재사용하고 /v1/kakao 요청을 별도 구현. 실제 계정의 API 규격/템플릿 승인/수신 테스트는 배포 후 확인 필요. 기존 소스에 알림톡 발송 구현은 없었음.
템플릿 (var1~var8 순서):
[임대차 월차임 납부 안내]

[*1*]님, 임대차계약에 따른 월차임 납부일을 안내드립니다.

■ 계약물건: [*2*]
■ 납부기한: [*3*]
■ 납부금액: [*4*]원
■ 입금은행: [*5*]
■ 입금계좌: [*6*]
■ 예금주: [*7*]
■ 지연배상금률: 연 [*8*]%

납부기한 내 월차임을 입금하여 주시기 바랍니다.
이미 납부하신 경우 본 안내는 참고만 부탁드립니다.
