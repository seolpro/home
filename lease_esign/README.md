# 온라인 주거용 임대차 전자계약 시스템

## 설치
1. ZIP 압축을 카페24 public_html 아래 원하는 폴더에 업로드합니다.
2. `storage/signatures`, `storage/pdfs`, `storage/logs` 폴더 권한을 755 또는 서버 환경에 맞게 설정합니다.
3. 브라우저에서 `https://도메인/설치폴더/install.php`를 실행합니다.
4. 설치 후 `install.php`를 삭제하거나 파일명을 변경합니다.
5. 관리자 로그인 후 새 계약서를 생성합니다.

## 흐름
- 관리자가 계약 생성 → 임대인 링크 발송 → 임대인 확인·서명 → 임차인 링크 발송 → 임차인 확인·서명 → 최종 PDF 생성 → 임차인에게 다운로드 링크 문자 발송

## 중요
- 반드시 HTTPS를 사용하세요.
- 주민등록번호 전체 대신 생년월일 앞 6자리만 입력하는 것을 권장합니다.
- `config.php`는 웹에서 접근되지 않도록 `.htaccess`가 적용되는지 확인하세요. 가능하면 DOCUMENT_ROOT 밖의 private_config로 옮기고 lib.php의 경로를 수정하세요.
- 본 프로그램의 서명은 서명 이미지, 동의, 시각, IP, User-Agent, 문서 해시를 기록합니다. 고액·분쟁 가능성이 큰 계약에는 본인확인 강화(휴대전화 인증, 공동인증, 전자서명 전문사업자)를 검토하세요.
- 최종 PDF는 브라우저의 html2pdf CDN을 사용합니다. 외부 CDN을 차단한 환경에서는 라이브러리를 로컬에 내려받아 경로를 변경해야 합니다.
- 문자 API는 계정별 최신 뿌리오 사양에 맞게 `send_sms()`를 조정할 수 있습니다.


## V1.1 뿌리오 문자 연동
- 뿌리오 `/v1/token`에서 Basic 인증으로 토큰을 발급한 뒤 Bearer 토큰으로 `/v1/message`를 호출합니다.
- 임차인 서명 완료 즉시 임대인과 설정된 서명완료 알림번호에 SMS/LMS를 발송합니다.
- 관리자가 최종 PDF를 생성한 뒤 임차인에게 보안 다운로드 링크를 발송합니다.
- 모든 발송 요청과 API 응답은 `sms_logs` 테이블에 저장됩니다.
- `config.php`의 인증키는 GitHub 등 공개 저장소에 올리지 마세요.
