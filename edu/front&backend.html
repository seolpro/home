직원 매뉴얼 쉽게 이해하는 IT 용어

프론트엔드 vs 백엔드

프론트엔드 = 사용자 화면, 백엔드 = 내부 시스템 (서버·데이터).
두 영역이 함께 움직여 한 개의 서비스를 완성합니다.

비유로 이해하기
프론트엔드 = 식당의 홀

고객이 직접 보는 공간: 인테리어, 메뉴판, 계산, 응대

화면(UI) 버튼/입력창 앱/웹의 겉모습
백엔드 = 주방

보이지 않는 내부 처리: 주문 접수, 조리, 재고·회원 관리

서버 데이터베이스 업무 규칙
서비스가 동작하는 흐름
프론트엔드 (사용자 화면)
  • 로그인, 조회, 신청 버튼을 클릭
  • 입력값을 확인하고 보기 좋게 표시
요청
응답
백엔드 (내부 시스템)
  • 회원·거래 데이터 저장·조회
  • 업무 규칙(승인/검증/정산) 처리
업무 예시로 이해하기
회원가입
  • 프론트엔드: 입력 폼, 오류 안내
  • 백엔드: 중복 확인, 저장, 환영 메시지
쿠폰 발송
  • 프론트엔드: 대상·메시지 선택
  • 백엔드: API 호출, 발송 기록 저장
통계 조회
  • 프론트엔드: 그래프 표시
  • 백엔드: 집계 계산, 권한 검증
직원 매뉴얼 문구 가이드
쉽게 말하기
  • “프론트엔드 오류” → “사용자 화면에서 오류가 발생했습니다.”
  • “프론트엔드 팀” → “화면을 담당하는 팀”
  • “프론트/백 간 연동” → “사용자 화면과 내부 시스템이 데이터를 주고받습니다.”
핵심만 기억
  • 프론트엔드 = 눈에 보이는 사용자 화면(UI)
  • 백엔드 = 보이지 않지만 핵심인 서버·데이터
  • 둘 중 하나만 멈춰도 전체 서비스에 영향
용어 간단 사전
UI / UX

UI는 화면·버튼 같은 겉모습, UX는 사용 느낌과 경험을 의미합니다.

클라이언트 / 서버

클라이언트는 사용자 기기(브라우저/앱), 서버는 내부 시스템입니다.

데이터베이스(DB)

회원·거래 등 중요한 데이터를 안전하게 보관하는 곳입니다.

이 페이지는 직원 교육·매뉴얼 배포용 인포그래픽 예시입니다.
