② 구글 시트 생성
  1. 새 스프레드시트를 생성합니다.
  2. 시트 이름 schema, join 2개를 만듭니다.
    3. ③ Code.gs에서 스프레드시트/시트 설정

    아래를 Code.gs 최상단이나 설정 블록에 추가/수정하세요.

    const CONFIG = {
  SHEET_ID: '🔁스프레드시트ID로_교체',   // 예: 1AbC...xyz
  SCHEMA_SHEET: 'schema',
  DATA_SHEET: 'join',
  SIGNATURE: { saveToDrive: true, store: 'url' }, // 선택
  FILE: { store: 'url' }                          // 선택: 'url'|'id'|'json'
};
    * 스프레드시트 ID는 주소의 /d/…/edit 사이 문자열입니다.
    * schema는 스키마 정의용, join은 접수 데이터 저장용입니다.
    ④ HTML(외부)에서 GAS Web App URL & FORM_KEY 설정

    프런트의 HTML 파일(외부 페이지)에 다음 상수를 추가/수정하세요.

    <script>
  const GAS_ENDPOINT = 'https://script.google.com/macros/s/🔁배포URL_ID/exec'; // 🔁 Web App 배포URL
  const FORM_KEY = 'join2025'; // 🔁 스키마의 formKey와 동일
</script>
    * GAS에서 배포 > 새 배포 > 유형: 웹 앱으로 배포 후 나온 URL을 넣으세요.
    * 프런트에서 이 값을 사용해 fetch로 스키마/제출을 호출합니다.
