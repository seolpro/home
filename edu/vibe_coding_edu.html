1교시 · 20~30분

AI에게 이렇게 요구하면 됩니다

좋은 프롬프트는 목적 + 사용자 + 입력항목 + 기능 + 환경 + 디자인 + 결과로 구성합니다.

Cafe24 PHP 8 환경에서 사용할 “조합원 명절 선물 배송지 수집 웹앱”을 만들어줘. 사용자는 휴대폰으로 접속한다. 입력항목은 성명, 연락처, 주소, 상세주소, 비고이다. 주소는 Daum/Kakao 우편번호 서비스를 이용해 검색하도록 해줘. 모바일 중심의 깔끔한 UI로 구성하고, 필수값 검증을 넣어줘. 신청 버튼을 누르면 추후 MySQL DB에 저장할 수 있도록 PHP 구조로 만들어줘. 관리자 화면에서는 신청자 목록을 검색하고 CSV로 내려받을 수 있도록 확장 가능한 구조로 설계해줘.
목적: 명절 선물 발송사용자: 조합원 입력: 성명·연락처·주소환경: Cafe24 PHP UI: 모바일 중심확장: DB·관리자·CSV
1교시 · 30~55분

실습: 명절 선물 배송지 수집 화면

아래 폼은 교육페이지 안에서 실제로 입력해 볼 수 있습니다. 주소검색 버튼도 작동합니다. 제출은 교육용 데모이므로 서버로 전송하지 않습니다.

AI에게 첫 수정 요청

지금 만든 신청화면을 모바일에서 한 손으로 입력하기 편하게 개선해줘. 입력창 높이를 충분히 키우고, 주소검색 버튼을 명확하게 보이도록 해줘. 제출 전에 필수값을 검사하고, 제출 완료 메시지도 보여줘.

두 번째 수정 요청

연락처는 숫자 입력에 맞게 처리하고, 주소는 사용자가 직접 수정하기보다 주소검색으로 선택하게 해줘. 상세주소는 별도로 입력받고, 개인정보 수집 안내 문구를 제출 버튼 위에 추가해줘.

좋은 오류 수정 요청

Cafe24 서버에 PHP 파일을 올렸는데 500 오류가 발생한다. 아래 오류 메시지와 코드를 보고 원인을 찾아줘. 수정 이유를 간단히 설명하고, 수정된 전체 파일을 다시 작성해줘.

AI에게 요청

지금 만든 배송지 입력 페이지를 MySQL DB와 연결해줘. PDO와 prepared statement를 사용하고, UTF-8(utf8mb4)로 저장해줘. 입력값 검증을 하고 성공 시 완료 화면으로 이동하도록 해줘. 필요한 CREATE TABLE SQL도 함께 만들어줘.
