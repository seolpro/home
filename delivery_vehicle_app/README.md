# 새벽배송 차량 사전등록 요청 (Cafe24 PHP/MySQL)

## 설치
1. PHP 7.4 이상(PHP 8.1+ 권장), PDO MySQL, cURL, mbstring, HTTPS 환경 확인.
2. DB에 `install.sql`을 phpMyAdmin으로 실행. 기존 테이블과 충돌하지 않도록 `dv_` 접두사 사용.
3. `config.example.php`를 `config.php`로 복사하고 DB 정보 및 `base_url` 수정.
4. 관리자 암호 해시 생성: `php -r 'echo password_hash("강력한비밀번호", PASSWORD_DEFAULT), PHP_EOL;'` 실행 후 `admin_password_hash`에 복사. PHP CLI가 없으면 임시 로컬 PHP 스크립트로 생성한 뒤 즉시 삭제.
5. 비즈뿌리오 `account`, `api_key`, `sender_profile`, `template_code`, `sender_phone` 설정. sender_profile에는 서비스에서 요구하는 발신프로필 키/식별자를 입력.
6. 파일을 `/delivery_vehicle/` 등에 업로드, HTTPS 접속 후 `admin.php` 로그인. 수신인 추가 후 발급된 링크를 기사에게 전달.
7. `config.php`는 웹 루트 외부에 두는 구성이 가장 안전합니다. 현재 배포는 .htaccess 접근 차단을 사용하므로 Apache 설정 확인 필수.

## 알림톡 연동 주의사항
`common.php`의 `ppurio_send()`는 비즈뿌리오 v1 토큰 발급과 `/v1/kakao` 요청 예시를 포함합니다. **실제 계정의 API 스펙, 필드명, 승인 템플릿의 본문/변수와 반드시 대조하여 수정 후 테스트하세요.** 제공 계정과 템플릿을 알 수 없으므로 발송 성공을 보장하지 않습니다.
현재 승인 신청용 본문은 다음과 같습니다:

[새벽배송 차량 사전등록 요청]

온라인마켓 : {마켓명}
방문예정일 : {방문일}
등록차량번호 : {차량번호}
접수일시 : {접수일시}

아파트 차량등록 시스템에서 해당 차량을 사전등록해 주시기 바랍니다.

비즈뿌리오 승인 템플릿이 `[ *1* ]` 등의 변수 체계를 사용하는 경우, 승인된 문안과 정확히 일치하도록 `$body` 조립부를 조정해야 합니다. 수신번호는 `dv_recipients`에서만 가져옵니다.

## 상태 설명
`accepted`는 API의 접수 성공으로, 실제 휴대전화 도착/읽음/아파트 출입 승인을 의미하지 않습니다. 최종 결과 확인은 비즈뿌리오 결과조회/콜백 추가 연동 필요.

## 운영·보안
- 링크는 48자리 랜덤 토큰이며, 관리자만 수신번호 수정/링크 재발급 가능.
- CSRF, PDO 바인딩, 출력 이스케이프, 관리자 비밀번호 해시 적용.
- 공개 URL에 대한 자동화 공격 방어를 위해 실제 운영 전 서버/WAF 레이트리밋 또는 CAPTCHA 적용 권장.
- `cleanup.php`는 CLI cron 전용. Cafe24 크론에 일 1회 등록하면 `retention_days` 이전 신청이 삭제됨.
- 차량번호는 개인정보일 수 있으므로 개인정보 처리방침, 이용 목적, 보유기간 안내를 실제 운영 환경에 맞게 추가할 것.
- 수신인 휴대전화번호 등록 시 본인 동의 확보. 공유 URL이 노출되면 누구나 요청할 수 있으므로 필요 시 재발급.
