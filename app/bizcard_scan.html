명함 촬영 → 자동 분석 → 연락처 저장

안드로이드 폰에서 명함을 촬영하거나 업로드하면, OCR로 이름/회사/직책/전화/이메일/주소/웹사이트를 자동 추출하고 즉시 연락처 저장용 vCard(.vcf)를 만들어 줍니다.

가장 현실적이고 안정적인 방식은 웹에서 자동 인식 후 연락처 저장용 파일 생성입니다. 이후 안드로이드 연락처 앱에서 저장 화면이 열리거나 가져오기(import)로 바로 저장할 수 있습니다.

2. 자동 입력된 연락처 확인

추출값은 사람이 한번 검수한 뒤 저장하는 방식이 가장 정확합니다.
안내
브라우저 웹앱은 안드로이드 연락처 DB에 아무 확인 없이 직접 “무조건 자동 저장”하는 방식은 제한적입니다. 대신 이 앱은 명함 인식 → 연락처 데이터 자동 채움 → 저장용 vCard 생성으로 가장 안정적으로 동작합니다. 생성된 VCF를 열면 안드로이드 연락처 앱에서 저장 흐름으로 이어집니다.
HTTPS 환경에서 모바일 홈화면에 추가(PWA)하면 더 앱처럼 사용할 수 있습니다.
