Japan Entry Assistant v1.0 (Cafe24 PHP 8.x)

설치:
1. ZIP 압축을 해제합니다.
2. japan_entry_assistant 폴더 전체를 Cafe24 /www/ 아래에 FTP 업로드합니다.
3. https://[내 도메인]/japan_entry_assistant/ 접속합니다.
4. HTTPS가 필수입니다(클립보드 복사, 모바일 촬영 안정성).
5. DB 생성, config, install.php 실행 불필요.

주요 기능:
- 모바일 반응형 화면
- 여권 사진 OCR (Tesseract.js CDN 로드 후 브라우저 내 처리)
- MRZ TD3 두 줄 파싱 및 여권번호/날짜 검증숫자 검사
- 수동 정보 입력 및 개별 복사 / 전체 복사 / TXT 저장
- 2026-10-19 연수 일정 샘플 (개인 여권정보는 포함하지 않음)
- 공식 Visit Japan Web 연결 및 체크리스트

개인정보 보호:
- 서버 업로드/DB/쿠키/localStorage/sessionStorage 사용하지 않음
- PHP는 HTML만 전송. 이미지 및 입력정보는 브라우저 메모리에서만 처리
- 외부 CDN에서 OCR 스크립트 및 영문 모델 파일을 내려받음. 여권 이미지를 CDN에 전송하도록 작성하지 않음
- 브라우저 확장프로그램, 악성 CDN, 클립보드, 사용자가 저장한 TXT까지 보호할 수 있는 것은 아님
- 운영 시 보안을 높이려면 Tesseract.js/worker/wasm/lang 파일을 검증 후 자체 서버에서 제공하도록 전환 권장
- 공유 PC에서 브라우저 종료 및 다운로드 파일 삭제 권장

제한:
- 공식 Visit Japan Web에 자동 제출하거나 공식 QR코드를 생성하지 않음
- OCR은 사진 품질에 따라 실패/오인식할 수 있으므로 원본 여권과 대조 필수
- MRZ 생년월일의 2자리 연도 해석은 휴리스틱이며 직접 검증 필수
- 공식 신고 질문(세관/입국심사)은 사용자가 직접 답변해야 함
- 여행 예시는 사용자가 제공한 일정으로, 항공권/예약증과 반드시 대조할 것
- 외부 CDN 접근이 제한된 망에서는 OCR이 실패할 수 있으나 수동 입력은 가능
