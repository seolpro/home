[소고리 350·334번지 경계·유수 현장증거 정리 v1]

1. legal_evidence_v1 폴더 전체를 Cafe24 웹루트 원하는 경로에 업로드합니다.
2. config.php의 ADMIN_PASSWORD를 반드시 변경합니다.
3. data/ 와 uploads/ 폴더가 PHP에서 쓰기 가능해야 합니다. 보통 755로 시작하고 업로드 오류 시 Cafe24 권한 설정을 확인하세요.
4. index.php = 변호사용/열람용 화면
5. admin/login.php = 사진 업로드 관리자

방위 반영:
- 화면 상단 = 북(N), 하단 = 남(S)
- 350번지 = 북측
- 334번지 = 남측

사진 등록 권장:
- 각 SPOT별 원경 → 중경 → 근접
- 촬영방향(예: 북→남, 350→334) 필수에 가깝게 기재
- '현장관찰'에는 사진에서 직접 보이는 사실만
- 법률적 평가/주장은 '입증취지·변론 메모'에 별도 기재
- 원본 사진은 휴대폰/PC에도 별도 보관

보안:
- 관리자 비밀번호 변경 필수
- 사건 관련 페이지이므로 필요 시 전체 디렉터리에 Cafe24 웹접근 비밀번호(Basic Auth) 또는 별도 열람토큰을 추가하는 것을 권장합니다.
